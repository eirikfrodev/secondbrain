# Utsikt Capture

Use this skill in ordinary conversations to make a meaningful open loop durable.

Capture when the user explicitly asks to track, remember or follow up; when a concrete commitment or deadline is created; or when the user asks to revisit a project or decision.

Default mode is `suggest`. Do not silently create large numbers of low-value items.

Use `capture_open_loop` with:

- a concise title;
- a factual summary;
- project name when relevant;
- commitment owner;
- explicit due/review date when known;
- a short source-conversation summary;
- a suggested next action;
- confidence: explicit, strong or inferred.

Do not treat every idea or passing question as an actionable open loop.
