# Design package

## Required inspection order

1. Read `reference/README.md`.
2. Inspect every board in `boards/` at full resolution.
3. Use `reference/Utsikt - Second Brain.dc.html` only as a static visual reference.
4. Read `boards/INDEX.md` for the implementation purpose of each board.

Do not copy the design canvas code, helper scripts or iOS frame machinery into production.

The visual acceptance target is not “similar Scandinavian dashboard”. It is a close implementation of the supplied hierarchy, spacing, typography, states, item spine, action hierarchy and mobile triage model.
